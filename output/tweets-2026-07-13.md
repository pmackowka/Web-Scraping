Model GPT-5.6 Sol od OpenAI może teraz działać wewnątrz Claude Code.

Są dwa sposoby, aby to zrobić, a oba wymagają kilku minut konfiguracji:

Opcja 1 — oficjalny plugin:
/plugin marketplace add openai/codex-plugin-cc
/plugin install codex@openai-codex
/reload-plugins, potem /codex:setup

Odblokowuje to /codex:review, /codex:adversarial-review i /codex:rescue. Claude pisze, GPT krytykuje, ty wypuszczasz kod.

Opcja 2 — proxy. Jeden alias sprawia, że Sol staje się twoim głównym modelem:

alias claudex='CLAUDE_CODE_SUBAGENT_MODEL=gpt-5.6-sol CLAUDE_CODE_ALWAYS_ENABLE_EFFORT=1 claude –model gpt-5.6-sol'

Bonus: Claude Code pozwala ustawić model subagenta i wysiłek samodzielnie.

Uruchomienia Sol Ultra mogą zużywać kilkukrotnie więcej tokenów niż podstawowe, więc prawidłowe przypisanie zadań delegowanych realnie oszczędza pieniądze.

> **Co to znaczy:** Ta integracja oznacza, że możemy używać Claude Code jako głównego interfejsu deweloperskiego, jednocześnie delegując ciężką pracę krytyczną modelowi GPT-5.6 Sol. To hybrydowe podejście łączy najlepsze cechy obu modeli — Claude do pisania kodu, Sol do adversarial review. W praktyce oznacza to lepszą jakość kodu bez zmiany środowiska pracy. Koszt to wyższe zużycie tokenów przy uruchomieniach Sol Ultra, ale right-sizing zadań delegowanych może to zbilansować. Warto przetestować obie opcje, aby zobaczyć, which pattern najlepiej sprawdza się w naszym workflow.
