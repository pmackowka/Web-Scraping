Hermes Agent Tip of the Day: 🪽

If you’re running GPT-5.6 with Hermes, there’s a brand new setting you should know about.

Hermes can now use OpenAI’s native Responses API server-side compaction for long-running sessions.

Turn it on:

compression:
  codex_responses_native: true

Here’s the cool part:

Instead of waiting for Hermes to locally compress a massive conversation, OpenAI can compact the older context server-side first.

Hermes then keeps the encrypted compaction checkpoint and replays it on future turns.

So you get:

→ Better long-session context management
 → Persistent compaction across turns
 → Less unnecessary transcript baggage
 → Hermes’ normal local compression still sitting there as a fallback

And this isn’t blindly enabled across every provider.

It’s specifically gated to GPT-5.6 running through the direct OpenAI API or your ChatGPT Codex subscription.

OpenRouter, xAI, Copilot, local models, etc. don’t get the field shoved at them and told “good luck.” 😂
